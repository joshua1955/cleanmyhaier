# - Haier smart-home stack (ru.haier.evo, com.haier.apps.evoSmart, com.haierubic.usmartdevice)
#   is only needed if you control Haier appliances from the TV.
# - Russian streaming apps are preloaded; keep only the ones you actually use.
# - Deliberately NOT in this list: com.cltv.fast (Live TV/tuner, iwedia), com.haier.overlay.tvcenter
#   (RRO for com.mediatek.wwtv.tvcenter), com.haierubic.usmartdevice (PERSISTENT, system uid,
#   INJECT_EVENTS/DEVICE_POWER), fusion.android.tv.demo (retail mode, system uid),
#   com.haier.oemmanualtest (factory test, system uid, ChangeSourceService). Disabling any of
#   these can break HDMI/source switching, the remote, or power control.
